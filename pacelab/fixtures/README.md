## Golden test rule (docs/CONTRACTS.md §3.4)

Both importers (C# in `sync/`, TS in `packages/data`) must turn `fit/easy-run.sanitized.fit`
into JSON equal to `canonical/easy-run.json` within the listed tolerances, ignoring
`source.importedAt` and `source.device`.

## Regenerating

```bash
pip install garmin-fit-sdk==21.218.0
python3 -I fixtures/tools/fit_to_canonical.py fixtures/fit/easy-run.sanitized.fit --imported-at 2026-01-15T13:00:00Z > fixtures/canonical/easy-run.json
python3 -I fixtures/tools/make_synthetic.py
```

Adding a real activity as a fixture: sanitize it first (move GPS, shift date, drop
user_profile), the way `easy-run` was done. Never commit an unsanitized file.
